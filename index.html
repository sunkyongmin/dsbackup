동신병원 배후진료 당직표 달력 만들기

연·월을 고르고 과별 당직 코드와 날짜별 메모(진료·내시경·휴진·연차)를 입력하면 아래에 A4 가로 달력이 만들어집니다.

1. 연·월, 공휴일

공휴일과 대체공휴일은 자동으로 들어갑니다. 임시공휴일·선거일은 "날짜=이름" 형식으로 직접 추가하세요. 칸을 모두 지우면 자동 입력으로 돌아갑니다.

2. 당직 코드

과별로 달력에 쓸 코드를 쉼표로 구분해 적습니다.

3. 당직 입력

1일부터 순서대로 숫자만 띄어 써서 넣거나(예: 1 3 3 1 …), 아래 달력에서 당직 코드를 눌러 바꿉니다. 누를 때마다 다음 코드로 넘어갑니다.

4. 메모

날짜별 메모: 아래 달력에서 각 칸의 "＋ 메모"(또는 이미 적힌 메모)를 누르면 그 날의 진료(토요일 오전 외래)·내시경·휴진·연차·기타를 적을 수 있습니다.

인쇄 창에서 용지 A4, 방향 가로, 여백 없음, 배경 그래픽 켜기를 선택하세요.

입력하는 즉시 이 브라우저에 자동 저장되어, 창을 닫았다 다시 열어도 이어서 작업할 수 있습니다. "백업 파일 저장"으로 받은 .json 파일은 직접 열어 보는 파일이 아니라, 이 페이지의 "백업 파일 불러오기"로만 여는 파일입니다. 보거나 공유할 달력은 "인쇄 / PDF 저장"으로 만드세요.
